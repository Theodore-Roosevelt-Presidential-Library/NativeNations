# NDNTA pilot invitation (draft)

**To:** North Dakota Native Tourism Alliance (contact from ndnta.com)
**Subject:** A directory that sends visitors to North Dakota's nations — would NDNTA review it first?

Hello,

The Theodore Roosevelt Presidential Library in Medora is building a free directory of the 573 federally recognized Native nations, built to send travelers to each nation's own tourism, events and visitor pages, and to NDNTA's. It copies nothing. Every listing is a short fact page that links out, with tracking so each nation and alliance can see the visits it sends.

Before anything goes public, the Library would like North Dakota's nations, through NDNTA, to be the first to review their pages. The draft lives at a private, unlisted address that search engines can't see:

- Spirit Lake Tribe: https://nativenations.labs.trlibrary.com/nations/spirit-lake/
- Standing Rock Sioux Tribe: https://nativenations.labs.trlibrary.com/nations/standing-rock-sioux/
- Turtle Mountain Band of Chippewa Indians: https://nativenations.labs.trlibrary.com/nations/turtle-mountain-chippewa/
- Sisseton Wahpeton Oyate: https://nativenations.labs.trlibrary.com/nations/sisseton-wahpeton-oyate/
- MHA Nation: https://nativenations.labs.trlibrary.com/nations/three-affiliated-tribes-fort-berthold/ (its history is held until the Nation reviews it)

What the Library is asking:

1. Are the links right, and which links should come first?
2. Is each nation named the way it wants to be named?
3. Each page has a short draft history and land history. Should they stay, change, or come down? A nation's own account always governs, and anything a nation asks to remove comes down.
4. Would NDNTA like its own listings or events featured on these pages, or the directory embedded on ndnta.com?

There is no deadline and no cost. A 20-minute call works too, if that's easier.

Thank you,
